# Collector and downstream automation redteam

Date: 2026-10-21. Scope: Collector capture, storage, public contract, deployment
and mutation scaffolding; Omi consumer and its Dagster/Windmill bindings.
This is a source review with synthetic regressions, not a claim that every
failure has occurred in production. Release and live acceptance are recorded
separately in WorkGraph OMIC-58 and the existing cutover task OMIC-55.

## Decision and boundaries

Keep the modular Collector and its existing state machines. Correct the
composition of their states rather than weakening the writer's READ_BEGIN
guard or swallowing errors. Keep internal audio/state in SQLite and immutable
public audio plus manifest in directories for atomic publication. Keep the
configured one-hour accumulation threshold; an indefinitely waiting remainder
is valid. Preserve reusable mutation results.

The deployed Collector had five v2 READY artifacts at inspection. Its consumer
checkpoint had the v2 marker and empty cursor, decisions, tail and ACKs.
The scheduled native Omi consumer was intentionally stopped during the
coordinated cutover. This does not establish downstream acceptance. An unrelated
team was also deploying Dagster control/notification changes; their stopped
sensors and stale snapshots were not treated as new independent defects.

## Method sequence and exclusions

Independent Sol reviewers inspected capture/storage, public contracts,
automation, and delivery/QA before the maintainer adjudicated findings.

| Order | Technique | Application |
| --- | --- | --- |
| 1 | Frame + assumptions | Separate successful capture, durable publication, consumption and notification; test the assumptions below. |
| 2 | Steelman + challenge | Preserve intentional batching, privacy redaction, source validation, and phased cutover before criticising them. |
| 3 | Premortem + inversion | Enumerate ordinary failure and misuse paths, then trace their preventing/detecting mechanisms. |
| 4 | ACH + five whys | Compare lifecycle misuse, storage failure and transport-only explanations for the crashes; trace the diagnostic loss separately. |
| 5 | Misuse + reversibility | Inspect destructive ADVANCE/ACK/GC, conflicting identities, missing readiness, migration and unsafe cleanup. |
| 6 | Incentives | Challenge green process health, enabled timers, test counts and mutation completion as proxies for delivered audio. |
| 7 | AI-check + calibration | Re-read callers, reject speculative findings, merge common causes, distinguish source reasoning from reproduction and live evidence. |
| 8 | Review + operational launch check | Require focused regressions, applicable local gates, exact deployed revision, real acceptance and preserved scheduler state. |

No separate culture or human group-facilitation workshop: no interpersonal
decision is being evaluated. Independent review implements the useful dissent
principle without inventing a workshop. No statistical outside-view forecast:
there is no comparable measured incident population. No strategic futures
exercise: concrete power, connection, process and disk failures are covered by
the scenario register. Standalone ideation/convergence, ladder, devil's-advocate,
RFC and record runs would repeat the alternatives, evidence grading and decision
already kept here and in WorkGraph. Launch marketing, sales, legal approvals
and compensation gaming do not apply to this private capture workflow.

## Assumptions and scenario register

Confidence is qualitative; no invented incident probabilities are used.

| Assumption / failure scenario | Sensitivity | Evidence and disposition |
| --- | --- | --- |
| A complete writer FSM makes every caller composition correct | Collapse | False: visit closure issued an illegal second checkpoint. Fixed and reproduced. |
| Lifetime submitted bytes describe the current READ leg | Degrade | False on recovery before READ_BEGIN. Current-leg settled receipt now determines safe reuse. |
| No newly submitted bytes means there is nothing to publish | Degrade | False after process restart with a retained prefix. New real-writer regression covers publication. |
| A saved receipt can outrank a later storage failure | Collapse | False: latched failure must win. Explicit failure precedence and negative regression retained. |
| Empty ACKs alone establish a migrated consumer | Degrade | False: marker, cursor, decisions and tail must also be valid and drained before activation. |
| Source validation is cheap even when repeated per speech range | Degrade | False by call graph. Composed read-count regression now bounds reads per operation. |
| Historical no-speech decisions must all remain forever | Degrade | False after settlement. Preserve only unresolved work and live tail/output boundary dependencies. |
| An active process will eventually announce readiness | Degrade | Not guaranteed. Successful observations without readiness now have a generous 900-second window. |
| A slow disk justifies discarding admitted work | Collapse | Rejected. Keep ownership, buffering and data safeguards; readiness observation does not cancel disk calls. |
| Quiet firmware periods imply missing audio frames | Degrade | Rejected. Preserve packet timeline/discontinuity facts without inventing an exact sleep duration. Small known frame loss remains quality statistics. |
| One-hour accumulation must flush whenever a drain closes | Degrade | Rejected. Existing user contract deliberately accumulates multiple small drains. |
| A healthy daemon or enabled timer proves processing/delivery | Degrade | Rejected. Inspect active state, fresh ticks, durable outputs and exact ACKs separately. |
| Passing ordinary tests completes the mutation campaign | Degrade | Rejected. Preserve native campaign receipts/results and report their status independently. |
| Mutation scratch can be deleted by name alone | Collapse | Rejected. Existing owner, process identity, token and cleanup-receipt checks were inspected and retained. |

For the three October 20 crashes, the observed outer stack pointed at
`BatchReconciler.close_visit` calling checkpoint. A healthy SQLite writer with
an interrupted READ reproduced that stack and exposed
`StagingWriterStateError`: READ_BEGIN was no longer active. A transport-only
explanation cannot explain the invalid follow-up command; a storage fault is
not required to reproduce it. The original inner exceptions were not retained,
so the historical journal alone cannot independently distinguish every inner
cause. New diagnostics retain bounded, redacted cause/context stacks at ERROR.

The causal chain was: disconnect -> durable interruption -> unconditional
visit checkpoint -> target rejects ended READ -> fatal wrapper. The separate
diagnostic chain was: raw error passed as positional data -> no standard cause
chain -> first event at DEBUG -> outer summary only. Both chains are corrected.

## Alternatives and rejected claims

Blanket suppression of WriterFailedError would hide real storage faults.
Restarting on every disconnect would conceal the state error and add downtime.
Allowing Prepared checkpoints to drain data would bypass READ_BEGIN; queued
pre-BEGIN data is explicitly possible. A global packet cache would introduce
stale validation and unbounded retention; snapshots instead belong to one
operation. Keeping all silence decisions would preserve the growth defect;
dropping silence still needed by an open tail would corrupt boundary handling.

No supported new timestamp, READY atomicity or ACK/GC data-loss defect was found
in the reviewed public paths. Manifests retain packet-coordinate timelines and
causal discontinuities; exact sleep duration is intentionally not invented.
Directory publication, checkpoint replace/fsync and exact ACK validation already
exist. Legacy readers and the stopped native v2 schedule were deliberate stages
of OMIC-55, not an excuse to enable an incompatible consumer during this audit.

The mutation review did not substantiate stale-report false completion or
unowned scratch deletion: receipt identity/fingerprint checks and cleanup
ownership checks already guard those paths. Unbounded SQLite busy handling
was not classified as a bug merely because a disk operation is slow.

## Irreversible actions and acceptance

ADVANCE and source deletion cannot be undone: require durable capture and exact
ACKs, respectively. Format activation is a forward transition: validate the
consumer first. Code installation and in-memory snapshot changes are reversible
at the code level but never justify discarding admitted audio or bypassing state
checks. Diagnostic redaction must continue to exclude messages, audio, secrets,
locals, absolute paths and source text.

Do not claim deployment from source tests, notification recovery from an enabled
timer, or cutover completion from five visible artifacts. Applicable local gates
and independent patch review precede installation; remote release work remains
off the local feedback path. OMIC-55 still requires one real bounded native
speech/no-speech result, durable checkpoint, released dependencies, exact ACK
and Collector retirement before obsolete paths are removed. Preserve the
deployment owner's scheduler state. Any identity conflict, corrupt storage,
missing durable output or failed local gate blocks that acceptance.
